# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be patient, and assume good intent.
Harassment, insults and personal attacks are not welcome here.

To report a problem, contact the maintainer, [@KashifManzer](https://github.com/KashifManzer), privately.
Reports are kept confidential.
